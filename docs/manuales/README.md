# Manuales de Uso — Índice

**Este directorio es distinto al resto de la documentación del repo.** Todo lo demás en `docs/` es especificación técnica para que Antigravity implemente el sistema. Esto es material de capacitación para las personas que van a usar el sistema una vez que existe.

Antigravity no necesita "implementar" nada de acá — estos documentos describen el sistema ya construido, en lenguaje simple, sin jerga técnica. Sirven para:
- Entrenar al equipo de SMG cuando el sistema esté listo
- Que Sebastián tenga algo a mano para resolver dudas básicas sin escribirle a Zelmar por cada cosa
- Onboarding de personal nuevo (un vendedor nuevo, un chofer nuevo)

---

## Convenciones de estos documentos

- Español simple, sin anglicismos técnicos
- Pasos numerados, no prosa explicativa
- Sin referencias a tablas, endpoints, o arquitectura
- Cada uno termina con el canal de soporte (WhatsApp Business a Zelmar / administracion@biteradigital.com)

Si el sistema cambia de forma que afecte cómo se usa (un botón se mueve, un flujo cambia), estos manuales se actualizan como parte de esa misma tarea — no son un documento que se escribe una vez y se olvida.
